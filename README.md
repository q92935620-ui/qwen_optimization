#  Оптимизация LLM на AMD RX 6750 XT (RDNA2) с помощью Triton

Этот проект посвящен запуску и оптимизации больших языковых моделей (LLM) на видеокартах AMD архитектуры RDNA2 (на примере RX 6750 XT) с использованием PyTorch, ROCm и кастомных ядер на языке Triton.

##  Аппаратная и программная конфигурация

*   **GPU:** AMD Radeon RX 6750 XT (12 GB VRAM, чип Navi 22, архитектура RDNA2, `gfx1031`)
*   **OS:** Ubuntu 24
*   **Стек:** ROCm 7.1+, PyTorch 2.12+rocm7.15, Hugging Face Transformers
*   **Модель:** Qwen2.5-3B-Instruct (FP16)

## Несколько но ...

Официальная поддержка ROCm для потребительских карт RDNA2 (особенно `gfx1031`) ограничена. Чтобы заставить PyTorch и видеокарту работать вместе, был применен обходной путь (override) через переменную окружения:

export HSA_OVERRIDE_GFX_VERSION=10.3.0

## Работа из коробки
Перед написанием кастомных ядер была замерена производительность «из коробки» (PyTorch eager mode, без использования torch.compile).

Методика: Генерация 100 токенов, замер через CUDA Events (после фазы прогрева).

Скорость генерации (Decode): ~13.09 токенов/сек


## Цель проекта
Написать кастомное слитое (fused) ядро RMSNorm на Triton, внедрить его в архитектуру Qwen2.5 и доказать, что ручная оптимизация позволяет обойти ограничения ROCm и ускорить генерацию токенов на потребительских картах AMD.
